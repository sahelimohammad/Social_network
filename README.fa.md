# Social Network — شبکه اجتماعی با جنگو

Social Network یک پروژه شبکه اجتماعی تحت وب است که با Django و Python پیاده‌سازی شده است. کاربران می‌توانند حساب بسازند، پروفایل خود را ویرایش کنند، پست منتشر کنند، به پست‌ها واکنش نشان دهند و در اتاق‌های گفتگو پیام بفرستند.

[English README](README.md)

## امکانات

- ثبت‌نام، ورود، ویرایش پروفایل و بازیابی رمز عبور
- ایجاد، ویرایش و حذف پست‌های متنی و تصویری
- ثبت کامنت و پاسخ به کامنت
- لایک و دیسلایک پست‌ها
- دنبال‌کردن کاربران و نمایش پروفایل آن‌ها
- جست‌وجو در متن پست‌ها
- اتاق گفتگوی بلادرنگ با WebSocket و Django Channels
- ذخیره پیام‌ها در پایگاه داده و استفاده از Redis برای ارتباطات بلادرنگ

## فناوری‌های استفاده‌شده

`Python`، `Django`، `Django Channels`، `Daphne`، `Redis`، `SQLite`، `Django REST Framework`، `HTML`، `CSS` و `JavaScript`.

## ساختار پروژه

```text
account/          ثبت‌نام، ورود و پروفایل
home/             پست، کامنت، لایک و جست‌وجو
chat/             اتاق گفتگو و پیام‌های WebSocket
pr2/              تنظیمات و مسیریابی Django و ASGI
manage.py         فرمان‌های مدیریتی
requirements.txt  کتابخانه‌های موردنیاز
.env.example      نمونه تنظیمات محیط محلی
```

## اجرای پروژه در ویندوز

پیشنهاد می‌شود Python 3.12 و Redis روی پورت `6379` نصب و اجرا شده باشند.

**۱. ساخت محیط مجازی و نصب کتابخانه‌ها**

در PowerShell و از داخل پوشه اصلی پروژه:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

**۲. تنظیم کلید محرمانه**

فایل `.env.example` را کپی و با نام `.env` ذخیره کنید:

```powershell
Copy-Item .env.example .env
python -c "from django.core.management.utils import get_random_secret_key; print(get_random_secret_key())"
```

کلید تولیدشده را مقابل `DJANGO_SECRET_KEY` در فایل `.env` جایگزین کنید. تنظیم حساب ایمیل برای اجرای محلی اختیاری است؛ اگر مشخصات SMTP را نگذارید، ایمیل‌های بازیابی رمز در ترمینال چاپ می‌شوند.

**۳. اجرای Redis برای چت**

اگر Docker نصب است، می‌توانید از این دستور استفاده کنید:

```bash
docker run --name social-network-redis -p 6379:6379 -d redis:7
```

اگر کانتینر قبلاً ساخته شده، از `docker start social-network-redis` استفاده کنید.

**۴. ایجاد پایگاه داده و اجرای سرور**

```bash
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver
```

سپس آدرس <http://127.0.0.1:8000/home/> را باز کنید. برای ثبت‌نام از `/account/register/` و برای گفتگو پس از ورود از `/chat/` استفاده کنید.

**۵. بررسی برنامه**

```bash
python manage.py check
python manage.py test tests
```

## نکات اجرا و انتشار

- پایگاه داده SQLite با اجرای Migrationها ساخته می‌شود. دیتابیس کاربران و پیام‌های واقعی در مخزن قرار ندارد.
- فایل‌های آپلودشده در پوشه `media/` ذخیره می‌شوند و به GitHub ارسال نمی‌شوند.
- قابلیت چت برای کارکردن به Redis نیاز دارد.
- دسترسی به اتاق‌های چت و اعتبارسنجی فرستنده پیام برای استقرار عمومی باید تقویت شود. نسخه فعلی مناسب اجرای محلی و نمایش پروژه است، نه پیام‌رسان عمومی.
- شاخه Django 4.2 دیگر پشتیبانی امنیتی دریافت نمی‌کند؛ پیش از استقرار عمومی باید به نسخه پشتیبانی‌شده مهاجرت و دوباره تست شود.
- پیش از انتشار مجدد تصاویر یا قالب‌های رابط کاربری، مجوز و شرایط انتساب دارایی‌های شخص ثالث بررسی شود.
